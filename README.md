# Interview Preparation 🚀

A **one-stop revision repository** for experienced software engineers targeting product-based MNCs.

The repository is designed for:
- Last-minute interview revision
- Experienced-level conceptual questions
- Practical, scenario-based questions
- Architecture and trade-off discussions
- Coding-adjacent Java/backend questions
- System design (HLD + LLD)
- Cloud, containers, Kubernetes and frontend fundamentals

## How to use

1. Pick the technology relevant to the interview.
2. Read only the questions first.
3. Expand the answer when you want to verify your understanding.
4. For final revision, use the **Quick Revision Checklist** at the end of each file.
5. Don't memorize answers verbatim. Be ready to explain **why, trade-offs, failure modes, and production experience**.

## Interview answer framework

For experienced-level questions, structure answers as:

**Definition → How it works → Why/when → Trade-offs → Production example → Failure/edge cases**

For system design:

**Requirements → Scale → APIs → Data model → HLD → Components → Data flow → Caching → Messaging → Consistency → Reliability → Security → Observability → Bottlenecks → Trade-offs**

## Target level

Primarily aimed at **5–12+ years of experience**, especially Senior Software Engineer, Senior Consultant, Lead Engineer and Staff-track interviews.

## Golden rule

If an interviewer asks **"Why?"**, don't stop at the definition.

If they ask **"What happens internally?"**, explain the mechanism.

If they ask **"What would you choose in production?"**, discuss trade-offs.
